## 二、本次升级改了什么

1. **整体质感**：深空紫黑底 + 香槟金 `#E3C480`，标题金色渐变裁切（`background-clip:text`），正文字距统一放宽，阴影分三层（近实、中柔、远光晕），全站去掉扁平色块。
2. **封面**：原本是一张横图硬裁成竖屏，左边缘会把新人切成半张脸。**已重新取景**——从 6000×4000 源图裁出城堡中段竖条（左边界锁在 46%，正好把人物排除在画面外），现在画面里只有城堡，5 座尖塔完整，天际线干净。
3. **相册**：从平铺网格彻底改为 **3D 翻书**。每张「书页」有正面（照片）与背面（纸纹），`rotateY(-180deg)` 翻转；翻页中的那一页始终置顶，翻完自动复位 z-index；连续快速点击会**逐页收敛**而不会跳页或卡住。
4. **结尾页**：`opacity:.5` + 双层渐变蒙版（径向聚光 + 上下压暗），并保留 30 秒极缓呼吸缩放，做氛围高潮而不牺牲文字可读性。
5. **音乐条**：屏幕底部常驻，**明确显示歌名《A Thousand Years》与演唱者 Christina Perri**，附唱片封面旋转动画、播放/暂停按钮、**音量滑杆**。未开启前显示「点击开启」脉冲提示。

### 本轮追加调整

6. **诚邀赴宴页改成半透明样式**：卡片从「实心米色纸卡」换成 **磨砂玻璃面板**——半透明渐变 + `backdrop-filter: blur()`、金色发丝双线边框、四角金色直角，文字改为象牙白 / 香槟金。卡片背后铺的是**同一张照片的虚化版**（7px 模糊、66% 透明度），所以透过卡片能看见光影层次。
7. **请柬页底部加了照片带**：用的是你指定的 `DQ6A1016`（城堡前牵手）。因为手机屏很窄（比例 0.46），横构图整屏铺满一次只能露出约 1/3 宽度、必然把人裁掉；改成**底部照片带**后，整张原图不裁、两人同框，顶部用渐隐蒙版融进暗场。
8. **结尾页人像居中**：原来取景窗偏左，只有新郎完整、新娘被切在画面外。现已重新取景（取景窗中心对准两人中点），**新郎新娘对称落在画面中央**，文字正好落在两人之间。
9. **相册说明文字改烫金**：页脚的「初见 · 一室暖光」和页码改成**金属渐变 + 压印高光**（上亮、中深、下亮的三段金属色阶，配白色压痕），看起来像真的烫金压印在纸上。
10. **修了一个烟花显示 bug**：结尾页原本用了 `mix-blend-mode:screen` 画烟花，在部分浏览器里会渲染成**深色圆盘**而不是光爆。已去掉混合模式、改用纯径向渐变光斑，并把尺寸收小，现在是柔和的光晕。

    /* … 共 12 项，cap 是翻书页底部的说明文字 … */

### 🖼 换照片

- **只换图**：替换 `assets/img/` 里的同名文件。各自规格：
  | 文件 | 比例 | 尺寸 |
  |---|---|---|
  | `book-01..12.jpg` | 3:4 | 880×1173 |
  | `hero-castle.jpg` | 0.62 竖 | 1080×1742 |
  | `chapter-1..3.jpg` | 1.9 横 | 1200×632 |
  | `finale.jpg` | 0.62 竖 | 1080×1742 |
  | `invite.jpg` | 3:2 横 | 1400×933 |
- **换构图**：改 `tools/make_assets.py` 里的 `PICKS`（源文件名 + 裁切锚点），跑一次
  `python tools/make_assets.py`，全部素材会按各自槽位比例重新裁好。

  锚点是**裁切窗口的中心位置**（0~1）：调小 = 保留更多左/上部，调大 = 保留更多右/下部。

  > 想换「诚邀赴宴」页底部那张照片，改 `PICKS` 里 `invite.jpg` 那一行的源文件名即可。
  > 换 `finale.jpg`（结尾合照）时，用 `python tools/preview_band.py 源文件名 0.5 0.6 0.7`
  > 可以预先看到「竖屏实际会露出哪一条」，挑好位置再填锚点——**横构图直接铺竖屏一定会裁掉大半**，
  > 先看再改能省很多返工。

### 🎵 换音乐

`assets/audio/bgm.mp3` 就是 `Christina Perri - A Thousand Years`（你给的 `.ncm` 是网易云加密格式、浏览器播不了，早前已解密转码）。换歌直接替换该文件即可，记得同步改 `music.title` / `music.artist`。

把 `musicUrl` 改成空字符串 `""`，页面会退回**内置 WebAudio 合成轻音乐**（音乐盒风格，C–G–Am–F 循环，零资源），适合先给客人看效果或临时演示。

> **加载策略**：音乐约 5 MB，页面先让照片加载，等 `load` 事件后才开始缓冲音频，避免首屏抢带宽；首次轻触时也能立刻出声。

## 五、朋友圈分享卡片怎么设置

### 标题和缩略图在哪改

在 `<head>` 里，搜 `✍️` 就能找到：

```html
<title>石山蒙 & 杜伊凡 · 婚礼邀请函</title>
<meta property="og:image" content="https://example.com/share-cover.jpg">
```

- **标题** = `<title>`，建议 20 字内，太长会被截断。
- **缩略图**：已做好 **`assets/share-cover.jpg`（600×600，75 KB）**，用的是**城堡全景**——纯建筑、辨认度最高，缩到 300px 依然一眼认出。
  部署时把它一起上传，再把 `og:image` 换成**它的绝对地址**即可。

### 两个必须知道的限制

1. **微信爬虫不执行 JS**，所以缩略图必须写死在 `<head>` 里，用脚本动态改没用。
2. **普通网页不能用 JS 自定义分享卡片**。`wx.updateAppMessageShareData` 那套需要 **认证公众号 + 已备案域名 + 后台配置 JS 接口安全域名**，个人链接用不了。卡片长什么样由微信抓取决定，你能控制的就是 `<title>` + `og:image` + 页面首图。

### 缩略图不更新？

微信有缓存。换图后**改文件名**或加参数（`share-cover.jpg?v=2`），再等几分钟重试。

## 六、分享时的注意事项

- **先发给"文件传输助手"自己点一遍**，确认能打开、音乐能响、翻书能翻、导航能跳，再发朋友圈。
- **iOS 微信禁止自动播放音频**，页面已做降级：首次轻触任意处开启音乐，右下角按钮可随时暂停。**别把"轻触开启"这一步删掉。**
- **iOS 上调不了网页音量**：系统把 `audio.volume` 设成只读，页面会自动把音量滑杆置灰并提示"请使用机身音量键"——这是预期的降级，不是 bug。
- **一键导航**：微信内点击会打开高德网页版，页面内可再唤起 App；iOS 上受微信限制不一定能直接跳 App，属正常现象。
- **单文件版适合私聊直发**；发朋友圈还是要用**链接**，微信不认本地文件。
- **别写诱导分享文案**（"转发给 10 个好友""集赞"），容易被判定违规降权。
- **朋友圈文案自己写**，链接卡片是系统抓的。正文里手写一遍"10月25日 雲蒙大酒店 18:18"更稳妥——很多人只看文字不看卡片。
- **更新后客人看到旧版**：微信缓存很顽固，改链接加版本号（`index.html?v=3`）最有效。
- **给长辈的说明**：可以在朋友圈补一句"点开后往下滑"，竖屏翻页对他们不总是直觉。

## 七、技术备注

- 自包含单文件：CSS / JS 全部内联，**零外部字体、零 CDN 依赖**，只有地图跳转一个外链（功能必需）。
- 首页取景窗比例（0.62）刻意做得**比所有机型的屏幕比例都宽**，这样 `object-fit:cover` 永远只裁宽度、不裁高度，**任何机型都不会切掉塔尖**。
- 桌面端：≥900px 且 ≥660px 高时，居中显示 430px 宽的圆角"手机舞台"，两侧是深色环境光 + 模糊城堡剪影；场景高度按舞台算（`min-height:100%`），不是 `100dvh`。
- 翻书：`perspective:1900px` + `preserve-3d`，每页 `.face.front`（照片）/ `.face.back`（纸纹）；纸纹是 `feTurbulence` 生成的噪点 data-URI。
- 翻页状态用 `pending / step()` 队列管理，**一律基于目标页 `pending` 递增**，所以连点不会吞页；`justDragged` 标记用来吞掉拖拽结束后浏览器补发的合成 `click`。
- 照片上加了 `draggable="false"` + `pointer-events:none`，避免拖图打断手势序列。
- 视口高度由 JS 写入 CSS 变量，规避 iOS / 微信 `100vh` 与地址栏抖动。
- 星光、金尘、烟花走单个 Canvas，粒子数按屏宽自适应，切后台自动停帧；结尾页的光爆用纯径向渐变（不再用 `mix-blend-mode`，避免被渲染成暗盘）。
- 请柬页的玻璃卡片用 `backdrop-filter: blur(16px)` 起雾，前提是**它背后确实有东西**——所以底层铺了同一张照片的虚化版；`.inv-photo` 用 `flex:1` 吃掉剩余高度，矮屏（667/568）也不会溢出。
- 相册页脚烫金用 `background-clip:text` + 三段金属渐变色阶，再叠两层 `drop-shadow` 做出压痕高光。
- 已按 **320×568 / 375×667 / 390×844 / 430×932 / Desktop 1440×900** 五种机型自动验算：
  每屏高度与舞台严格相等、无纵向溢出、无横向裁切、无遮挡、翻书状态机 20+ 条断言全通过。
